# NEEDY GIRL OVERDOSE 再現仕様 --- 行動コマンド

> 数値は攻略情報を実装向けに整理したもの。細部の版差・攻略情報間の差に備え、すべて設定ファイルから変更可能にする。

## 1. 共通

主要パラメータ:

``` ts
interface GameState {
  day: number;
  time: "day" | "evening" | "night";
  stress: number;
  stressCap: 100 | 120;
  affection: number;
  darkness: number;
  followers: number;
}
```

通常、昼・夕に行動し、夜に配信する。行動によって1ターンまたは2ターン進む。

## 2. あそぶ

### ゲーム

-   消費: 1ターン
-   ストレス -4
-   好感度 +2
-   やみ度 ±0
-   ゲームボーナス +1

### こみゅにけーしょん

好感度により内容を自動分岐する。

  条件                  表示             ストレス   好感度   やみ度 ボーナス
  --------------------- -------------- ---------- -------- -------- ------------
  好感度 \< 40          トーク                 -3       +2        0 コミュ力+1
  40 \<= 好感度 \< 80   いちゃつく             -6       +4       -1 経験+1
  好感度 \>= 80         傷のなめあい          -10       +6        0 なし

### えっちなこと

通常時: - ストレス -12 - 好感度 +15 - やみ度 -6 - 経験 +1

同日におくすりをGO!状態で使用済み: - ストレス -12 - 好感度 +20 - やみ度
+6 - 経験 +1 - 迫力 +1

実行回数を記録すること。一定回数以上で `Nymphomania`
を発生させる。攻略情報に回数差があるため閾値は設定値化する。

  ディパス         適量           1         -1       -1 \-
  ディパス         GO!            2      約-12       +6 迫力+1

-   弱い薬のストレス低下量にはやみ度依存補正がある可能性があるため関数化する。
-   GO!を実行した日は `overdosedToday = true` とする。
-   まほうのきって使用回数を記録し、一定回数で `Rainbow Girl`。
-   100万人記念配信後はおくすりを無効化する仕様を持たせる。

## 7. コマンド実行後の共通処理

``` text
executeCommand(command):
  1. command availability を判定
  2. command固有イベントを再生
  3. パラメータ変化を適用
  4. 0..cap に clamp
  5. ボーナス経験値を加算
  6. 配信ネタ解放判定
  7. 行動回数・薬使用回数等のカウンタ更新
  8. 即時エンディング条件判定
  9. 時間を進める
  10. 時間進行後イベントを判定
```

## 8. 即時チェックが必要な値

-   `affection == 0` -\> NeToRare
-   `affection >= 100` -\> Os-Alien
-   `darkness == 0` -\> Healthy Party
-   `stress >= 120` -\> Bomber Girl（前提イベント・タイミングを考慮）
-   えっちなこと回数 -\> Nymphomania
-   まほうのきって使用回数 -\> Rainbow Girl
-   JINE未読放置回数 -\> Crossing the line
