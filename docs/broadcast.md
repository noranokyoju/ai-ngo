# NEEDY GIRL OVERDOSE 再現仕様 --- 配信システム

> 目的:
> コーディングエージェントがゲームロジックを再実装できるよう、攻略情報を「状態・条件・効果」の形に整理する。
>
> 基準: Steam版の名称を優先する。家庭用版では一部名称が異なる。
>
> 注意:
> 攻略Wiki間で細部に差異・未確定情報がある箇所は、実装時に定数化して調整可能にすること。

## 1. 配信ネタの基本ルール

-   配信ネタはジャンルごとにレベルを持つ。
-   原則として同ジャンルの前レベルを配信済みであることを次レベル解放の前提とする。
-   同じ行動から複数候補が得られる場合があるため、ネタ解放判定は「未解放か」「前提レベルを配信済みか」を確認する。
-   高レベルのネタにはフォロワー数による実質的な進行制限がある。目安は
    Lv3=1万人、Lv4=10万人、Lv5=25万人。
-   記念配信「インターネットエンジェル」は通常ジャンルとは別枠で、フォロワー数の閾値到達時に解放する。
-   配信を行うとストレスが増加し、フォロワーを獲得する。獲得量には下記ボーナスを適用する。

## 2. フォロワーボーナス

### 2.1 連続配信ボーナス

全配信に適用する。

``` text
streakMultiplier = consecutiveStreamDays + 1
```

例:

    連続配信日数   倍率
  -------------- ------
               0     x1
               5     x6
              10    x11
              20    x21
              28    x29

-   通常の配信を行った翌日も配信すると連続日数を維持・増加。
-   配信せずに日付をまたぐとリセット。
-   強制配信イベントは連続配信として扱う。
-   配信不能期間を発生させるイベントでは、結果的に連続配信が途切れる。

### 2.2 ゲームボーナス

対象: `ゲームじっきょう`

``` text
gameMultiplier = 1 + gameLevel * 0.5
```

-   `あそぶ > ゲーム`: gameLevel +1
-   `ゲームじっきょう`配信でも上昇
-   目安上限: Lv60

### 2.3 経験ボーナス

対象: `えっちなはいしん`, `ASMR`

``` text
experienceMultiplier = 1 + experienceLevel * 0.5
```

上昇行動: - `あそぶ > えっちなこと` -
`あそぶ > こみゅにけーしょん > いちゃつく` - `いんたーねっと > であい`

目安上限: Lv60。

### 2.4 迫力ボーナス

対象: `やみはいしん`

``` text
impactMultiplier = 1 + impactLevel * 0.5
```

上昇行動: - `おくすり`をGO!状態で使用 - GO!後の`えっちなこと` -
`やみはいしん`

### 2.5 はるまげ度

陰謀論配信を進めるほど、全体のフォロワー増加効率を低下させる。

``` text
harumagedonMultiplier = 1.0 - harumagedonLevel * 0.01
```

参考レベル: - Lv1 -\> x0.99 - Lv5 -\> x0.95 - Lv33 -\> x0.67 - Lv73 -\>
x0.27

### 2.6 シネフィル

対象: `オタクトーク`。倍率は x1.0 固定として扱う。

### 2.7 事前告知

`いんたーねっと > SNS`の一部行動で付与。

``` text
announcementMultiplier = 1.2
```

-   次回配信に適用。
-   重複しない。
-   日付変更で消滅。

### 2.8 コミュ力

全配信対象。攻略情報では、表示上のコミュ力ではなく経験レベルを参照している可能性があるため、再現時は独立した設定項目にする。

``` text
communicationMultiplier = 1 + experienceLevel * 0.1
```

## 4. 推奨データ構造

``` ts
type StreamGenre =
  | "chat" | "game" | "angel_explain" | "conspiracy"
  | "net_lore" | "asmr" | "sexy" | "dark"
  | "otaku" | "challenge" | "pr" | "internet_angel";

interface StreamTopic {
  id: string;
  genre: StreamGenre;
  level: number;
  title: string;
  unlock: UnlockCondition[];
  immediateEndingId?: string;
}

interface StreamBonusState {
  consecutiveDays: number;
  game: number;
  experience: number;
  impact: number;
  harumagedon: number;
  cinephile: number;
  communication: number;
  announcement: boolean;
}
```

## 5. 実装上の優先順位

1.  ネタの解放条件
2.  配信済みフラグと同ジャンルの順次解放
3.  連続配信ボーナス
4.  各ジャンルボーナス
5.  記念配信のフォロワー閾値
6.  配信による即時エンディング判定
